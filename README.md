# Gerador de QR Code - Projeto ADS SENAI

Este projeto é uma aplicação web simples desenvolvida para a disciplina de [Inserir Nome da Disciplina, ex: Programação Web/Front-end] do curso de **Análise e Desenvolvimento de Sistemas (ADS)** do **SENAI**.

O objetivo desta aplicação é permitir que o usuário insira um texto ou URL e gere, instantaneamente, um QR Code correspondente utilizando a biblioteca `qrcode.js`.

## 🚀 Tecnologias Utilizadas

Este projeto foi desenvolvido utilizando as tecnologias base da web:

- **HTML5**: Estruturação da página.
- **CSS3**: Estilização e layout responsivo.
- **JavaScript (ES6)**: Lógica de programação e manipulação do DOM.
- **QRCode.js**: Biblioteca externa para renderização do QR Code.

## 📁 Estrutura do Projeto

A estrutura básica do projeto é composta pelos seguintes arquivos:

- `index.html`: Estrutura da interface do usuário.
- `style.css`: Estilos aplicados ao container e elementos.
- `script.js`: Lógica de geração do QR Code.
